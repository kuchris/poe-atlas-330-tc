# 輿圖天賦樹 3.30 繁中

《流亡黯道》3.30 輿圖天賦樹的繁體中文互動網頁，支援搜尋、配點、效果加總及以網址分享配點。

- 網頁內容來自[公開的繁中 Artifact](https://claude.ai/artifact/RdWKg7J1CsahuBE7rXfP4s)。
- [英文原版](https://hypostasis.faith/atlas/data.html)。
- 本專案是非官方玩家工具，與 Grinding Gear Games 並無關聯。

網站為靜態檔案，可直接開啟 `index.html`，或使用任何靜態網站伺服器。

## 儲存配點

點好天賦後，按「存檔」，輸入名稱並按「儲存」。之後可從清單選擇存檔，再按「載入」；亦可保存多套配點。

存檔只保存在目前的瀏覽器。清除網站資料或使用私人瀏覽模式可能會刪除存檔；複製網址可以把目前配點分享或留作備份。
